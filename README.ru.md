## От замысла до редактируемого видео

Vids Studio объединяет навык создания видео с инструментами управления **той вкладкой Google Vids, которую вы явно подключили**. Навык помогает со смыслом, кадрами, голосом, темпом, звуком и проверкой. Коннектор наблюдает редактор и выполняет действия внутри вкладки. Проект остаётся редактируемым в Vids.

- **Творческий процесс:** сцена строится вокруг события; границы речи и планов различаются; изображение, речь, звук и понятность проверяются отдельно.
- **Два клиента, одна основа:** отдельные идентификаторы Codex и Claude Code, общий runtime и координация доступа к одному документу.
- **Рабочий стол остаётся вашим:** без системных мыши, клавиатуры, буфера обмена и вывода окон на передний план.
- **Свидетельство перед повтором:** свежие снимки интерфейса, квитанции действий и явное восстановление при неизвестном исходе.
- **Локальные помощники:** графика, листы кадров, анализ медиа и manifest дублей с сохранением предыдущих версий.

Это независимый неофициальный проект автоматизации интерфейса. Он не предоставляет API сцен Google Vids, не обходит ограничения аккаунта и не включает доступ к Google AI. **Поддерживаемая и проверенная платформа установки — Linux.** Задание `export_mp4` экспериментальное: изолированные браузерные тесты проходят, но живая проверка текущего экспорта Google Vids ещё ожидается. [Границы и свидетельства →](docs/ru/testing.md)

## Один репозиторий, два профиля

| | Codex | Claude Code |
| --- | --- | --- |
| MCP-сервер | `google-vids` | `vids-claude` |
| Навык | `google-vids` | `vids-director` |
| Расширение Chrome | Vids Studio | Vids Studio · Claude |
| Native host | `com.vids_studio.bridge` | `com.vids_studio.claude_bridge` |
| Установка | Материализованный каталог `codex` | Материализованный каталог `claude` |

Профили работают с разными документами независимо. Для одного документа управление получает одна задача, другая — `CONTROL_BUSY`. Координация действует после обновления host и расширения обоих профилей. Ручной ввод человека в документе она не блокирует.

## Начало работы

Нужны **Node.js 22.13+**, **Python 3.11+**, **Bun** и **Google Chrome 118+** на Linux. Записанная проверка выполнена с Node 24 и Chrome 148; каждая минимальная версия отдельно не испытывалась. Для проверки экспорта и медиа нужны FFmpeg/ffprobe. Также требуются собственная установка Codex или Claude Code и доступ к Google Vids.

Склонируйте исходники и создайте постоянную установку Codex:

```sh
git clone https://github.com/Shugar86/vids-studio.git
cd vids-studio
python3 scripts/build_profiles.py --profile codex --target ../vids-studio-codex --write
cd ../vids-studio-codex
bun install --frozen-lockfile
python3 scripts/setup.py --profile codex
python3 scripts/setup.py --profile codex --install
```

Для **Claude Code** используйте `--profile claude` и отдельный каталог, например `../vids-studio-claude`. Первый вызов setup показывает план; `--install` регистрирует native host, MCP и ссылку на навык. Посторонние настройки сохраняются, конфликтующие регистрации останавливают установку. Установщик не загружает расширение и не подключает вкладку.

1. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите каталог `extension` этой установки.
2. Откройте нужный Google Vids, нажмите соответствующее расширение и подключите вкладку.
3. Обновите подключение MCP в клиенте. Попросите выполнить `vids_diagnostics` и `vids_status`: нужны `compatibility.ready: true`, `attached: true` и правильный документ.

Не перемещайте каталог установки: в настройках сохранены пути к нему. Установка обоих клиентов, архивы, обновление и откат описаны в [полном руководстве](docs/ru/installation.md).

## Дайте агенту задачу

> Используй навык google-vids в подключённом Google Vids. Сделай 35-секундный ролик о продукте для новых пользователей, на русском. Покажи проблему, одно конкретное действие и результат. Нужны спокойный голос и читаемые субтитры. Сначала собери и проверь характерное начало, затем доведи ролик до конца и проверь экспорт, если он доступен.

В Claude Code назовите навык **vids-director**. Можно поставить точечную задачу: сократить начало, заменить кадр, исправить субтитры или улучшить звук. [Процесс, примеры запросов и критерии проверки →](docs/ru/usage.md)

## Что внутри

| Компонент | Назначение |
| --- | --- |
| [`skill/`](skill/) | Входные навыки клиентов, общие творческие рекомендации и медиа-помощники |
| [`server/`](server/) | MCP-инструменты, проверка аргументов и долговременные задания экспорта |
| [`native/`](native/) | Native Messaging host, закрытый Unix socket и координатор документа |
| [`extension/`](extension/) | Драйвер Chrome debugger, popup и наблюдение загрузки |
| [`profiles/`](profiles/) | Раздельные публичные идентификаторы двух клиентов |
| [`scripts/`](scripts/) | Сборка профилей, установка, выпуск архивов и живая проверка чтения |
| [`tests/`](tests/) | Unit-тесты, изоляция процессов и проверки в отдельном Chromium |

Коннектор не читает cookie и пароли, не ищет другие вкладки и не открывает публичный TCP-порт. Сам Google Vids продолжает отправлять Google обычные запросы редактора и загружаемые медиа; наблюдения и снимки поступают вашему AI-клиенту. [Разрешения, данные и восстановление →](docs/ru/architecture.md)
