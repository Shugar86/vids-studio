# Profiles and installation / Профили и установка

- [English: installation, client profiles, updates and rollback](en/installation.md)
- [Русский: установка, профили клиентов, обновление и откат](ru/installation.md)

The common source builds separate Codex and Claude Code installations. A build changes files; explicit extension reload, tab reconnect and client refresh activate them.

Общий источник собирает отдельные установки Codex и Claude Code. Сборка меняет файлы; явные reload расширения, подключение вкладки и обновление клиента активируют их.
