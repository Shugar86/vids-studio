# Short local motion inserts

Use a deterministic short insert when exact timing, a diagram, staged interface
or controlled object action serves the brief and this preparation route is
already authorized. Vids still owns the final assembly, scene timing and mix.
One imported clip is not a set of editable native objects. A mixed workflow does
not imply transferring the entire film to another editor.

## Responsibilities and available runtime

Use real footage for claims about real product behavior. A staged interface or
animation can explain a relationship if its fictional status is clear. Separate
subject action, camera movement and overlay animation; a cursor/check mark alone
does not prove the modeled state changed.

Choose an already available renderer that can perform the needed action. If
Remotion/HyperFrames is available and authorized, use its actual documented
render/check path and relevant skill. A skill directory does not prove a CLI is
installed. Do not claim a renderer name when another implementation made the clip.

A small owned HTML/SVG composition can be rendered through isolated headless
Chromium and existing ffmpeg: an explicit frame/time function, a finite image
sequence, then encoding. This is a local composition, not arbitrary browsing.
Use no user browser profile, OS input or clipboard; keep resources local, block
network requests and bound parallelism. Do not run an unrelated upstream pipeline,
auto-setup, provider fallback or paid generation to obtain a single insert.

## Contract and checks

Keep the purpose and real-versus-demonstration status; initial state, action and
result; identity invariants; dimensions/fps/duration; action and readable hold;
source/resource provenance; actual render command; output/range/audio status and
review evidence beside the source.

Lay out the most demanding final frame before animating. Drive custom animation
by absolute `frame / fps`, not wall-clock time, accumulated requestAnimationFrame
or randomness. Wait for local fonts/assets. The same timestamp must produce the
same frame after forward and backward seeks. One motivated accent and readable
hold can be stronger than continuously moving panels.

1. Inspect the beginning, maximum complexity, state changes, last frames and all
   important motion. Playback where possible; a sampled sheet cannot prove feel.
2. Verify duration, dimensions, decode, text clipping, blank frames and unintended
   audio. Silent inserts need no audio. MP4/H.264 does not promise alpha support.
3. Import through an observed supported Vids upload. Verify actual geometry,
   playback in/out and separate scene duration; file creation is not insertion.
4. Mix voice/music/neighbors in Vids and account for any embedded insert audio.
5. Review the native export at the same boundaries. A clean local clip does not
   prove a clean Vids trim. Recheck properties and neighbors after replacement.

If the route cannot finish with available authorized tools, preserve the source
and tested sample, then identify the missing step. Do not claim an import, heard
sound or complete new film from one local MP4.
