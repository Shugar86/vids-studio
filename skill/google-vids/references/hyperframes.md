# Необязательная локальная вставка HyperFrames

Общий scope — в [motion-inserts.md](motion-inserts.md). Используй только уже доступный и разрешённый renderer. Найди CLI в текущем проекте/настройке и проверь его версию/help; личный путь другого проекта не является зависимостью. Не устанавливай ничего из этой справки автоматически и не называй другой renderer HyperFrames.

Ресурсы композиции держи локальными. Для стороннего runtime и шрифтов сохрани источник и применимую лицензию; копии GSAP или шрифтов в этот skill не включены. Перед загрузкой ресурсов проверь scope. Если CLI документирует отключение телеметрии/автообновления, используй его поддерживаемые настройки; не считай неизвестную env-переменную гарантией отсутствия сети.

Для детерминированной композиции: явные размер, fps, длительность и фаза удержания; состояние по абсолютному времени, без wall-clock/random/unbounded loops; готовые шрифты перед кадром; одинаковый результат при seek назад и вперёд. Разделяй transform по контейнерам, если конфликтующие tweens портят геометрию. Раскладку и читаемость проверяй по кадру, не только по линтеру.

После текущих документированных check/render команд проверь локальный клип через `qa_export.py` и просмотр. Ограничь параллельность по ресурсам машины. Отсутствие аудио у немой вставки ожидаемо. Импортируй клип в Vids, проверь размер, playback range, длительность сцены и соседние стыки; чистый локальный render не доказывает готовую сборку.
