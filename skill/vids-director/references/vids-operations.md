# Профиль Claude

Общие действия и ограничения — в [operate-vids.md](operate-vids.md). Эта справка добавляет только клиентские отличия; исторические координаты, частные документы и чужие настройки не нужны для работы.

- MCP: `vids-claude`; расширение: **Vids Studio · Claude**. Используй установленную сборку профиля Claude и её diagnostics; пути установки и extension ID определяются текущей установкой, не личным примером. Сборка Codex не заменяет этот профиль.
- Инструменты могут быть отложенными: используй доступный ToolSearch/discovery. Не делай вывод о работе MCP по наличию его имени. При `CONTROL_BUSY` не забирай управление.
- Загрузку/reload расширения и подключение вкладки выполняй только разрешённым установочным путём; не открывай системное управление для обхода требований фоновой работы.
- Native text, object geometry, timing, captions, upload и export проверяются по общей справке и текущему observe. Поля типа `mode: reconcile`, неизвестные квитанции и свежие snapshot действуют одинаково для обоих клиентов.
- Дополнительные helpers — в [client-tools.md](client-tools.md). Низкоуровневый `vids_call.mjs` использует ту же установленную MCP-сборку; он не даёт привилегий обхода. Для standalone копии явно укажи `VIDS_CLAUDE_BRIDGE`; helper проверяет `profile.json` и отказывается запускать чужой профиль.
- Design/канвас раскадровки — необязательная клиентская возможность. При отсутствии используй таблицу и кадры; это не причина задерживать монтаж.

При восстановлении сохрани старое неизвестное действие, наблюдай реальный документ и выполни native reconciliation до новых намерений. Новый job recovery требует нового writer token; не передавай прежний token другому процессу.
